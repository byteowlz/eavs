# Scheme provenance

`eavs-dark.json` is the eavs graphite/lime look ("Eavs Control Room"), copied
unchanged from `ui/control-room/src/theme.js` (`controlRoomScheme`, ADR-0008).
It is the existing eavs identity, not a new visual decision. There is no light
variant yet; one needs a Design Studio decision before it ships.

`example-dark.json` / `example-light.json` are the template's starter palette,
kept only for the mechanism's tests.
